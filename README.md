# 金融證照歷屆題庫互動測驗系統 (Exam Web)

> 專為臺灣金融證照考試量身打造的極致輕量、無須伺服器後端之單頁式（SPA）互動測驗系統。收錄 **6,620 題** 歷屆與官方標準題庫，支援跨證照（投信投顧、期貨商業務員、共同科目）自由複選抽題、關鍵字專題出題、錯題自動歸檔與 Google 帳號跨裝置雲端同步。

* 🌐 **線上測驗正式網址**：[https://renart00001-ux.github.io/exam-web/](https://renart00001-ux.github.io/exam-web/)
* 🚀 **託管與自動化部署**：GitHub Pages + GitHub Actions CI/CD
* 📊 **題庫總容量**：共 6,620 題
  - 📗 **投信投顧相關法規**：105–115 年歷屆 36 梯次共 1,800 題
  - 📙 **期貨商業務員**：105–115 年歷屆 37 梯次雙科共 3,700 題（期貨交易法規 1,850 題 ＋ 期貨交易理論與實務 1,850 題）
  - 📘 **共同科目**：113 年金融市場常識 504 題 ＋ 113 年職業道德 616 題共 1,120 題

## 🌟 核心功能特色

1. **跨證照、跨年度與跨科目自由複選抽題與全量出題雙模式**：
   - **🎛️ 分頁式測驗範圍選單（License Category Tabs）**：重塑選單為 4 大分頁（📗 投信投顧、📙 期貨商業務員、📘 共同科目、📌 我的錯題庫），各分頁即時呈現勾選題數徽章。
   - **⚡ 快速情境預設**：提供「⚡ 近 1 年」、「⚡ 近 3 年」、「⚡ 近 5 年」、「全選本類別」與「清空」一鍵快速勾選，並支援「近期 111–115 年」與「歷屆 105–110 年」年度折疊分組，解決選單過長難以操作的問題。
   - **雙模出題機制**：
     - **🎲 隨機抽 50 題模式**：每題 2 分，滿分 100 分，70 分及格。
     - **📚 全量出題模式**：選取的題庫每題皆出（支援 50 至 6,620 題，徹底杜絕漏題），分數採「作答正確比率 (%)」精確計算，70% 及格。
2. **🎯 關鍵字專題出題引擎**：
   - 輸入考點關鍵字（如：`開放式`、`處分`、`主管機關`、`基差`、`保證金` 等）。
   - 搭配目前勾選的測驗範圍即時檢索出題；若勾選範圍無符合題目，提供一鍵跨全題庫 6,620 題檢索出題。
3. **🚨 反向題型／否定關鍵字自動紅字粗體**：
   - 正則自動辨識「何者非、不正確、不包含、不包括、不適當、不正當、不屬於、不屬、不當、不能、不承保、不在、不可、非屬、錯誤、有誤、為非、非為、不是、不得、不符、未符」等字詞，防止審題粗心失分。
4. **📑 三段錯誤選項灰階速記**：
   - 提供「淺灰、中灰、極淺灰」三段淡化干擾選項，聚焦正確答案，大幅提高考前記憶效率。
5. **☁️ Firebase Auth 與 Cloud Firestore 跨裝置同步**：
   - 支援 Google 帳號一鍵登入，手機、平板、電腦錯題本即時雙向同步。
   - 訪客離線模式（localStorage）與會員雲端模式雙軌並行，支援 JSON 檔案備份匯入與匯出。
6. **📄 官方原始 PDF 試卷雙軌查核**：
   - 每題均附官方試題與解答 PDF（全站收錄 148 份官方 PDF），智慧切換本機離線相對路徑與 Google Drive 雲端檢視連結。
7. **📱 手機響應式面板與深色/折疊優化**：
   - 頂部控制欄支援一鍵收折，保留最大可視閱讀題幹空間。
8. **💡 考點提示與 📘 試題解析雙向擴充機制**：
   - **💡 考點提示 (Hint)**：題目出現即時可視；以常理暗示或極端詞破綻引導解題思維；僅限管理員帳號（`renart.00001@gmail.com`）具備編輯改寫權限，點選送出即刻生效。
   - **📘 試題解析 (Explanation)**：作答完畢後動態開展；A/B/C/D 四個選項逐一提供精準法規依據與錯誤破綻；開放所有登入帳號共同補充，送出改寫並留存「Last edited by [帳號] at [時間]」透明化稽核紀錄。
   - **⚡ 5,500 題專業科目提示與解析全量完工**：針對投信投顧 1,800 題與期貨商 3,700 題歷屆試題，全面預載高品質標準提示與逐選項解析，100% 達成去識別化。
